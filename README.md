## 🇬🇧 English

> *"Engineering is not just understanding how a system works — it's making it smarter, more accessible, and more effective."*

I'm **İhsan Kumuma**, a Mechanical Engineering student at Mersin University who refuses to fit in one lane. I build at the intersection of **mechanical systems, artificial intelligence, embedded software, and entrepreneurship** — as an engineer, founder, and product builder.

My method, always the same loop:

<div align="center">

```
   PROBLEM  →  RESEARCH  →  ARCHITECTURE  →  PROTOTYPE  →  TEST  →  PRODUCT
```

</div>

I don't wait for perfect conditions. I build what works with what I have — because an idea's value is measured by how real it becomes, not how impressive it sounds.

<br/>

### 🏛️ Empty Ventures

**[Empty Ventures](.)** is the venture studio I founded to merge disciplines under one technology roof — where ideas are researched, prototyped, tested, and turned into real products.

```
Start with a big idea.
Build small systems that actually work.
Solve real problems.
Rebuild, relentlessly.
```

<br/>

### 🚀 What I'm building

<table>
<tr>
<td width="50%" valign="top">

**🧠 EmptyOS**
AI-agent orchestration OS for company operations — specialized agents for research, architecture, dev, QA, docs & ops, coordinating a full build pipeline end to end.

**🔗 OpsFlowID**
Operations & identity management platform for teams — task management, org structure, and workflow visibility, shipping to web + mobile (Flutter).

**🎙️ AI Dubbing Platform**
Full pipeline: speaker diarization → timestamped ASR → context-aware translation → emotion analysis → voice cloning → expressive TTS → timeline editing & lip-sync optimization. Exploring Whisper, Fish Speech, Chatterbox, XTTS, Sesame CSM, Seed-VC.

**🕸️ Noesis**
AI decision-support system that unifies scattered data — knowledge graphs, vector search, RAG, anomaly detection & explainable decision support. Modular core, inspired by (not copying) large-scale data platforms.

</td>
<td width="50%" valign="top">

**📷 Visual Vibrometry (TÜBİTAK 2209)**
Camera-based, contactless predictive maintenance — classifying rotating-equipment faults (imbalance, misalignment, looseness) from video motion analysis instead of physical sensors.

**🪐 MER-Steering Rover Team**
~20-person university rover team building toward ARC/URC/ERC — 48V BLDC drivetrain, independent wheel control, ROS 2 stack, autonomous nav, robotic arm.

**✈️ Teknofest Combat UAV**
Fixed-wing autonomous UAV — X-UAV Talon airframe, Cube Orange FC, Jetson vision stack — target detection, tracking, geofencing, fail-safe logic.

**🌱 Hayalden Gerçeğe**
Community & academy bringing student engineering teams (rover, rocket, e-mobility, UAV) together to turn ideas into real prototypes.

</td>
</tr>
